# Tema Natural Mystic

Personalização CSS da loja Natural Mystic na Nuvemshop.

## Arquivos principais

- `natural-mystic-theme.css`: fonte principal e legível; edite este arquivo.
- `natural-mystic-theme.min.css`: versão minificada, gerada a partir da fonte principal.
- `METODOLOGIA-TEMA-NATURAL-MYSTIC.md`: decisões visuais, processo de teste e publicação.
- `AGENTS.md`: instruções de manutenção do projeto.

## Publicação

O repositório será conectado ao Cloudflare Pages. A Nuvemshop deverá importar o arquivo CSS público usando uma URL versionada para evitar cache antigo.

Não altere manualmente o arquivo minificado. Depois de editar a fonte principal, regenere-o mecanicamente e valide as páginas em desktop e mobile conforme a metodologia.
